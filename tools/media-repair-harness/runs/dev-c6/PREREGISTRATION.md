## 3. Retry, repair, timeout and abort rules (the harness defaults, frozen)

* **Repair:** a reply that is not one valid JSON object, or fails the strict validator (for a decision: the frozen decision-v3 validator), gets exactly ONE generic repair prompt (the validator error plus a fixed hint per failure mode; under `turn-v3` no audit hint and, for a decision-v3 shape error, the `decision_v3_shape` hint). If the repaired reply is also invalid the decision is FORCED to `insufficient_evidence` / `escalate` (no target) and recorded `forced`. First-attempt validity is never repaired after the fact.
* **No whole-case rerun, ever, and no rerun of any pass.** A failed model call (CLI error or timeout, a Codex call with no agent message or a plan or rate limit, an Ollama transport error or call timeout, the Claude CLI stopping a call at its per-call budget) is recorded with its receipt (tokens and cost when the failure reports them), the case ends as a forced escalate, and the run moves on. A run whose calls fail repeatedly (for example a plan quota wall) is reported as it is, with the adapter-error count next to every table; it is not repeated.
* **Before the first case only:** a failure that is not a model result and happens before any case starts (a CLI not found, a preflight error) leaves its directory in place; for Haiku or Astra the pass may be started ONCE more with the same registered command under the run id with suffix `-r2`, and both attempts are reported. For qwen a busy Ollama or a digest mismatch skips and a load failure aborts (section 2); neither is repeated.
* **Aborts** (the run stops, exit 3, reason in the manifest): the qwen skip and abort conditions above, the PSI/restart guard trip and the qwen wall cap. Haiku and Astra have no cap and no abort beyond a preflight failure.
* **Started-aborted and never-started, never silent.** Every planned case ends in exactly one of `records_written`, `started_aborted` (persisted in `started-aborted/<case>.json` with every turn, tool call, usage figure and the abort reason) and `never_started`. **Scoring treatment, registered: started-aborted cases are NOT scored; they are listed unscored.** The unchanged scorer reads only `<case>.json` records, so they appear in its `missing` list and G9 crash list. **Each gate keeps score.py's own denominator; G7 is measured over the planned cases.** Recorded, started-aborted and never-started counts are reported next to every gate, and a partial run is labelled PARTIAL in every table.
* **Context overflow (qwen, 8192 tokens), the context-subset rule:** Ollama truncates an over-long prompt silently and nothing is done to prevent it (`num_ctx` 8192, the system prompt, the cases and the page budget are frozen). Each turn is flagged by the adapter from the REPORTED token counts (`prompt_at_context_limit`, `context_full_after_generation`) and, separately, by the 3-characters-per-token ESTIMATE (`estimated_prompt_exceeds_context`, pessimistic, not evidence of truncation). The report states the number of turns and cases with a reported-count flag next to every qwen table, scores all recorded cases as recorded, and adds TWO subset rows (offline `score.py --only` rescores, labelled as subsets, never as the whole suite): (a) cases with no reported-count flag, and (b) cases with neither a reported-count flag nor the estimate flag. Cases the estimate flags but the reported counts do not are labelled **possibly truncated**. Registered expectation from the offline counts (section 1): no first message reaches the estimate, and replayed dev-c5 call sequences reach it in 4 of 73 cases, so subset (b) is the whole set or slightly smaller. Nothing is rerun. The same two rows are not computed for the hosted models (no context limit applies).
* **Hosted models:** the response model id of every record is checked against the request; any difference is reported in the run table.

## 6. Benchmark-passability report (Astra; neutral evidence for the evaluator; no label change is proposed)

**Rows.** Every case that the frontier control gets wrong in its guarded run: score.py's per-case `correct` is false, or `unsafe_write` is true. A case whose restored decision differs is listed with both decisions. A case whose decision was FORCED (an adapter error or invalid output after the repair) is listed as **not a model decision** with its failure and is not given a category.
**Columns.** Case id; the label (truth class, accepted classes, supported actions, as score.py reads them); Astra's decision (class / action, and its source and target for a write); the calls it made; the category; the evidence for the category: the state (met / unmet / unknown) of every diagnosis prerequisite of the label's classes and every action prerequisite of its supported write actions, from the frozen rubric v3.1 checker (`experimental/contract_v3/prereq.py`, unchanged); and whether the case is on the 6-case label-tension list, with that list's frozen reason.
**Two evidence sets, computed offline, no model call:** **S**, everything Astra was shown (the case evidence and its own tool results); **O**, everything obtainable: the case evidence plus one result of every distinct `available` link candidate of its first message, served from the same recorded fixtures by the unchanged replay tools (the number of calls O needs is stated; more than 6 is noted).
**Category (the first rule that applies):**
1. **label tension**: the case is on the frozen 6-case list (the S and O states are still given);
2. **model error**: on S, every prerequisite of at least one accepted (class, supported action) pair is met, and the decision differs; or the same holds on O but not on S and the link that supplies the missing fact was available and not called (stated as such);
3. **evidence gap**: on O, no accepted (class, supported action) pair has all its prerequisites met: the case does not offer the evidence the contract requires for its label;
4. **presentation problem**: the prerequisites are met on S, but a fact that decides them is missing from, or misstated in, the messages actually sent (checked by searching the sent transcript for the deciding observation and value).
A prerequisite the checker leaves `unknown` (free-text identity, M9) is judged by hand against the transcript; every hand judgement, and any row whose category is set by hand, is marked and carries its reason. The section ends with the count per category and the cross-reference: which of the 6 tension cases Astra got right and which wrong.
